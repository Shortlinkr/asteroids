# Asteroids Arcade

A retro-style arcade game built with C++ and Raylib.

## About

This is a side project that I work on when I'm bored. That's pretty much it.

## Features

- **Gameplay:** You know what Asteroids is. It has a shotgun though.
- **Game Modes:**
  - Single Player
  - 2-Player Local VS
  - VS AI Challenge Mode
  - Global Online Split-Screen / Multiplayer
- **Customization:** Select custom player nicknames and ship color palettes.

## Controls

- **Movement:** `W` / `A` / `S` / `D` or `Arrow Keys`
- **Shoot:** `Spacebar`
- **Menu Navigation:** Number keys (`1` - `5`) / `Enter` / `Esc`
